# 2026-05-08 工作日志

## 多AI工坊工具 (独立HTML)

构建了一个 GitHub Pages 兼容的独立 HTML 单页应用「多AI工坊」，核心功能如下：

### 一对多模式 (One-to-Many)
- 2x3 网格布局，默认嵌入 ChatGPT、DeepSeek、通义千问、Kimi、豆包、元宝
- 顶部共享输入框 + "发送到全部"按钮
- 每个 AI 面板内嵌对应网站 iframe，被限制时自动显示"在新标签页打开"兜底
- 底部每个面板有手动输入区，可粘贴 AI 的回答
- 可自定义 AI 列表（名称、网址、颜色、启用/禁用）

### 群聊头脑风暴模式 (Group Chat)
- 左侧参与者列表（含"我"+4位AI角色：理性分析、创意先锋、实战派、反方辩手）
- 每位AI有预设人格和发言模板，模拟讨论轮转
- "开始头脑风暴"按钮开启讨论模式
- 想法板自动收集灵感
- 讨论摘要自动生成
- 预设讨论话题（环保方案、碳足迹产品、AI未来预测、知识管理）
- 玩法说明引导

### 设置
- AI列表管理（增删改）
- 参与者管理（名称、角色、个性、颜色）
- 预设话题一键加载
- 数据导入导出、重置

### 技术细节
- 纯前端单 HTML 文件，无外部依赖
- localStorage 持久化所有配置和数据
- 绿色主题、卡片式布局、移动端适配
- 参考了 ChatALL（多AI并行）、xmy-ai（iframe嵌入方案）、multibot-chat（多模型聚合）等项目的设计思路

## 第二次更新 - Chrome插件 + iframe嵌入修复
- 研究了用户下载的 xmy-ai-chrome-plugin 源码，核心使用 `declarativeNetRequest` API 移除 `X-Frame-Options` 和 `Content-Security-Policy` 响应头
- 创建了专属 Chrome 插件「多AI工坊 Helper」覆盖13个AI网站
- 插件 manifest v3，background service worker 使用 `modifyHeaders` 规则
- 更新 HTML：增加插件状态检测横幅（已安装/未安装）、插件安装指南页面（4步图文引导）、更好的 iframe 加载状态管理和刷新按钮

## 第三次更新 - AI角色选择系统（用户自主选角组队）
- 新增「选角组队」独立页面（导航栏第2个Tab）
- 建立 12 种 AI 角色池：理性分析、创意先锋、实战派、反方辩手、技术专家、用户体验师、商业顾问、设计思考者、数据科学家、行业观察者、心灵导师、未来预言家
- 每种角色有独特的颜色、角色名、人格描述和 3 套发言模板
- 用户点击角色卡片即可选入/取消，最多选 4 位组成团队
- 顶部团队预览区实时展示已选成员（带序号和删除按钮）
- 确认组队后自动跳转群聊页面
- 群聊页面增加「更换团队成员」按钮，可随时回选角页调整
- 数据存储迁移：用 selectedRoleIds 数组持久化用户选择，群聊参与者自动同步
